CHAT MODE:
──────────

    ↓

    ↓
Context maintained for conversation

────────────
User Prompt → gemini_cli.py → Gemini API → Response → Terminal
(Single request, no history)


IMAGE MODE:
───────────
Image File → PIL (Pillow) → gemini_cli.py → Gemini Vision API
    ↓
Analysis → Response → Terminal

Issue: "API Key not configured"
    ↓
Check .env file exists?
    ↓ No → Create .env file
    ↓ Yes
    ↓
Check GEMINI_API_KEY value?
    ↓ Placeholder → Get real API key
    ↓ Real key
    ↓
Test with: python test-gemini.py


Issue: "Module not found"
    ↓
Check Python version?
    ↓ < 3.8 → Upgrade Python
    ↓ >= 3.8
    ↓
Install: pip install google-generativeai pillow


Issue: "Connection error"
    ↓
Check internet connection?
    ↓ No → Connect to internet
    ↓ Yes
    ↓
Check API key valid?
    ↓ No → Get new API key
    ↓ Yes
    ↓
Check firewall/proxy settings
