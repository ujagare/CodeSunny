📋 OPTION 1: LOCAL TESTING (NGROK - RECOMMENDED FOR TESTING)
═══════════════════════════════════════════════════════════════════════

STEP 1: Install ngrok (5 minutes)
───────────────────────────────────────────────────────────────────────
1. Go to: https://ngrok.com/download
2. Download ngrok for Windows
3. Extract ngrok.exe to a folder
4. Open Command Prompt in that folder

STEP 2: Start Webhook Server (1 minute)
───────────────────────────────────────────────────────────────────────
Open terminal in mcp-server folder:

python whatsapp_webhook.py

You'll see:
🚀 WhatsApp Webhook Server Starting...
📡 Listening on port 5001
🔗 Webhook URL: http://localhost:5001/whatsapp

Keep this running!

STEP 3: Expose with ngrok (1 minute)
───────────────────────────────────────────────────────────────────────
Open NEW terminal where ngrok.exe is:

ngrok http 5001

You'll see:
Forwarding: https://abc123.ngrok.io -> http://localhost:5001

Copy the https URL (e.g., https://abc123.ngrok.io)

STEP 4: Configure Twilio Webhook (2 minutes)
───────────────────────────────────────────────────────────────────────
1. Go to: https://console.twilio.com
2. Left sidebar: Messaging → Try it out → Send a WhatsApp message
3. Scroll down to "Sandbox Configuration"
4. Find "WHEN A MESSAGE COMES IN"
5. Paste your ngrok URL + /whatsapp
   Example: https://abc123.ngrok.io/whatsapp
6. Method: POST
7. Click "Save"

STEP 5: Test It! (1 minute)
───────────────────────────────────────────────────────────────────────
1. Send a message from your WhatsApp to +14155238886
2. Type: "I need a website"
3. You should get AI-powered reply instantly!

✅ If working: Congratulations! Two-way communication active!
❌ If not working: Check webhook server logs for errors

📋 OPTION 2: PRODUCTION DEPLOYMENT (RENDER/RAILWAY)
═══════════════════════════════════════════════════════════════════════

For permanent webhook (not just testing):

STEP 1: Deploy Webhook to Render
───────────────────────────────────────────────────────────────────────
1. Create account: https://render.com
2. New → Web Service
3. Connect GitHub repo
4. Build Command: pip install -r requirements.txt
5. Start Command: python mcp-server/whatsapp_webhook.py
6. Environment Variables:
   - GROQ_API_KEY
   - GEMINI_API_KEY
   - WEBHOOK_PORT=10000
7. Deploy

You'll get URL like: https://your-app.onrender.com

STEP 2: Configure Twilio
───────────────────────────────────────────────────────────────────────
1. Go to Twilio Console
2. Sandbox Configuration
3. WHEN A MESSAGE COMES IN: https://your-app.onrender.com/whatsapp
4. Save

Now it works 24/7 automatically!

🎯 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════

1. Customer sends WhatsApp message
   ↓
2. Twilio receives message
   ↓
3. Twilio sends to your webhook
   ↓
4. Your webhook processes with AI
   ↓
5. AI generates contextual reply
   ↓
6. Webhook sends reply back to Twilio
   ↓
7. Customer receives AI reply instantly

All automatic! No manual intervention!

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Issue: "Connection refused"
→ Make sure webhook server is running
→ Check port 5001 is not blocked

Issue: "ngrok not found"
→ Download from ngrok.com
→ Extract and run from that folder

Issue: "Webhook not receiving messages"
→ Check Twilio webhook URL is correct
→ Must be https (ngrok provides this)
→ Must end with /whatsapp

Issue: "AI not responding"
→ Check GROQ_API_KEY or GEMINI_API_KEY in .env
→ Check webhook server logs for errors
