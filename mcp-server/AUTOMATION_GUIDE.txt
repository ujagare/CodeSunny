🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Issue: "No leads found"
  → Add test leads via chatbot or manually to data/leads.json

Issue: "SMTP error"
  → Check .env SMTP credentials
  → Verify Zoho Mail Pro settings

Issue: "MongoDB error"
  → System automatically falls back to JSON storage
  → No action needed

Issue: "AI generation failed"
  → Check GROQ_API_KEY or GEMINI_API_KEY
  → System uses fallback templates
